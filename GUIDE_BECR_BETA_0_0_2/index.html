Guide BECR — bêta 0.0.2

BECR permet aux animateurs de lancer des commandes Minecraft avec des boutons. Chaque bouton peut enchaîner plusieurs commandes avec des temps d’attente.

Configuration testée : Minecraft Java 1.21.8, Fabric, Minescript 5.0b11 for Fabric 1.21.8. Nous n’avons pas vérifié d’autres versions.

Installer Minecraft et Minescript

  1. Installez CurseForge, puis ouvrez Minecraft dans l’application.
  2. Créez ou choisissez un profil Minecraft 1.21.8 avec Fabric.
  3. Dans ce profil, avec Add Content / Ajouter du contenu, ajoutez Minescript 5.0b11 for Fabric 1.21.8 et Fabric API compatible avec Minecraft 1.21.8. Vérifiez les versions des fichiers avant de les installer.
  4. Si Python 3 n’est pas déjà installé, installez-le depuis le site officiel ou le Microsoft Store.
  5. Démarrez Minecraft depuis ce profil CurseForge au moins une fois. Minescript doit créer son dossier, notamment le fichier config.txt.

Si votre profil avec Minescript fonctionne déjà, gardez-le.

Installer BECR

  1. Téléchargez et lancez BECR-Beta-0.0.2-Setup.exe. Suivez les étapes de l’installateur, puis ouvrez BECR avec le raccourci créé.
  2. Au premier démarrage, BECR demande de choisir votre dossier minescript existant. Dans CurseForge, ouvrez le dossier du profil Minecraft que vous utilisez, puis choisissez son dossier minescript : c’est celui qui contient config.txt. Ne choisissez pas le dossier BECR.
  3. BECR place console_listener.py dans ce dossier et prépare son démarrage automatique. Vous n’avez normalement pas besoin de copier ce fichier ni de taper \console_listener dans le chat.
  4. Lancez Minecraft avec ce profil et rejoignez un monde ou votre serveur. Si le jeu était déjà ouvert lors de l’installation de BECR, fermez-le puis relancez-le avant de vérifier la connexion.
  5. Dans le chat Minecraft, BECR affiche normalement un message avec [BECR] en orange et le texte suivant en blanc. Dans la fenêtre BECR, attendez « ● Connecté » en haut à droite.

BECR ne remplace pas automatiquement une autre règle de démarrage présente dans Minescript. S’il trouve un ancien démarrage MCECR, il vous demande avant de le remplacer et conserve une sauvegarde. Pour une autre règle déjà présente, suivez le message affiché plutôt que de modifier le fichier vous-même.

Repérer la fenêtre

  • Profil : groupe de boutons pour un événement.
  • Event : mode pour lancer les boutons dans Minecraft.
  • Édition : mode pour préparer profils et boutons ; cliquer sur un bouton dans ce mode ne le lance pas.
  • ● Connecté / ● Non connecté : état de la communication avec Minecraft.
  • Journal des commandes : messages en bas de la fenêtre pour suivre ce qui se passe.

Créer un profil et un bouton

  1. Passez en mode Édition. Cliquez sur Nouveau profil, donnez-lui un nom, puis choisissez-le dans le menu Profil.
  2. Cliquez sur + Action : une action est un bouton. Donnez-lui un nom et, si vous le souhaitez, une couleur avec Couleur du bouton.
  3. Ajoutez ses commandes comme expliqué ci-dessous, puis cliquez sur Enregistrer l’action.

Un bouton sans commande peut être enregistré, mais il ne lancera rien. Les profils sont conservés dans le dossier profils de BECR : gardez-en une copie avant une mise à jour ou un changement d’ordinateur. Ne publiez pas vos profils personnels par mégarde.

Ajouter et modifier des commandes

Chaque étape est une commande accompagnée, si besoin, d’un temps d’attente avant son lancement.

  1. Écrivez une commande dans Commande Minecraft (sans /), par exemple say Début de l'événement. Ne mettez pas / au début.
  2. Dans Délai avant (s), mettez 0 pour ne pas demander d’attente, ou indiquez un nombre de secondes entre 0 et 86400.
  3. Cliquez sur Ajouter l’étape. Répétez pour les autres commandes ; elles seront lancées dans l’ordre de la liste.
  4. Pour changer une étape, sélectionnez sa ligne, corrigez la commande ou le délai, puis cliquez sur Modifier l’étape. La sélection reste visible quand vous cliquez dans un autre champ.
  5. Pour enlever une étape, sélectionnez-la et cliquez sur Supprimer l’étape sélectionnée. Terminez toujours par Enregistrer l’action.

Exemple : say Début de l'événement avec 0 seconde, puis say Deuxième annonce avec 5 secondes. BECR attendra le délai de la deuxième étape avant de lancer la seconde annonce. L’éditeur peut signaler certaines erreurs et proposer Appliquer la suggestion, mais ne garantit pas qu’une commande fonctionnera dans Minecraft.

Ranger les boutons

En mode Édition, attrapez « ↔ Déplacer ↕ » pour déplacer un bouton. Ranger en grille remet tous les boutons en place et remplace leurs positions choisies à la main. Éditer rouvre un bouton ; Suppr. le supprime après confirmation.

Lancer un événement

  1. Lancez Minecraft depuis le bon profil CurseForge et rejoignez le monde ou serveur. Attendez que BECR indique « ● Connecté ».
  2. Choisissez le bon Profil, puis passez en mode Event.
  3. Cliquez une seule fois sur le bouton voulu et consultez le Journal des commandes. Les commandes sont vraiment envoyées au jeu : vérifiez leur résultat dans Minecraft.

Testez vos boutons dans un monde adapté avant un événement en direct.

En cas de problème

  • « ● Non connecté » : vérifiez le bon profil CurseForge, que vous avez rejoint un monde, puis redémarrez Minecraft si BECR a été installé alors que le jeu était ouvert. Vérifiez que le dossier minescript choisi lors du premier démarrage est celui du profil utilisé.
  • BECR redemande un dossier : sélectionnez le dossier minescript existant qui contient config.txt, pas le dossier du logiciel BECR.
  • Minescript ne fonctionne pas : vérifiez Minecraft 1.21.8, Fabric, Minescript 5.0b11 pour Fabric 1.21.8, Fabric API compatible et Python 3.
  • Un bouton ne fait rien : vérifiez que BECR indique « ● Connecté », que vous êtes en mode Event et que le bouton contient une commande. Regardez le journal.
  • Une commande ne marche pas : retirez le / initial dans BECR et vérifiez sa syntaxe ainsi que vos permissions dans Minecraft. Le journal peut indiquer qu’une commande a été envoyée sans prouver qu’elle a eu l’effet attendu.
  • Un profil manque : vérifiez vos fichiers dans le dossier profils de BECR et restaurez votre sauvegarde si nécessaire.

Pour signaler un bug, notez le profil, le bouton, ce que vous attendiez, ce qui s’est produit et le message du journal BECR.
