Badlands Event Control Room (BECR)

Console locale pour les animations sur Minecraft Java. BECR permet de préparer des boutons qui lancent des commandes dans le jeu avec Minescript, puis de les regrouper par profil. Par ItzMichel en feat avec Perplexity.

Bêta 0.0.2

Configuration testée : Minecraft Java 1.21.8, Fabric, Minescript 5.0b11 for Fabric 1.21.8 sur Windows. Les autres configurations n'ont pas été validées.

Animateurs : lisez le guide complet d'installation et d'utilisation avant le premier lancement. Il explique l'installation avec CurseForge, le choix du dossier Minescript, les profils, les boutons et le dépannage.

Installation Windows

Téléchargez BECR-Beta-0.0.2-Setup.exe depuis la publication de la bêta lorsqu'elle sera disponible. Installez BECR et ouvrez-le avec le raccourci créé. Au premier démarrage, choisissez le dossier minescript existant du profil Minecraft utilisé : il doit contenir config.txt. BECR y installe son fichier et prépare son démarrage automatique. Rejoignez un monde dans Minecraft et attendez que BECR indique « Connecté ». Ne copiez pas le fichier à la main si l'installation s'est bien passée.

Si un ancien démarrage MCECR est détecté, BECR demande votre accord avant de le remplacer. Une autre règle universelle déjà présente peut empêcher l'installation : suivez alors le message affiché.

Utilisation rapide

  • Event : cliquer sur un bouton lance ses étapes dans Minecraft.
  • Édition : créer des profils, ajouter ou modifier des boutons et leurs commandes, changer leur couleur et leur place, ou utiliser « Ranger en grille ».
  • Journal des commandes : « envoyée au jeu » ne signifie pas que le serveur a exécuté la commande. Vérifiez le résultat dans Minecraft. Écrivez les commandes sans / initial.

Sauvegardez vos profils avant une mise à jour. Dans la version installée sur Windows, ils sont enregistrés dans %APPDATA%\BECR\profils et les réglages dans %APPDATA%\BECR\becr_settings.json. La désinstallation ne supprime pas ces données personnelles ni le fichier BECR placé dans Minescript.

Lancement depuis les sources

Pour les personnes qui travaillent sur le code : installez Python avec tkinter et Minescript dans un profil Minecraft compatible. Gardez les fichiers du dépôt ensemble, puis lancez python BECR.py. Choisissez votre dossier minescript existant au premier lancement. Dans ce mode, les profils sont dans profils/ à côté de BECR.py, et les réglages dans becr_settings.json. Pour changer de profil Minecraft utilisé par BECR, fermez BECR, supprimez seulement ce fichier de réglages puis relancez l'application et choisissez l'autre dossier. Sur la version installée, le fichier à retirer pour changer de profil Minecraft est %APPDATA%\BECR\becr_settings.json : ne supprimez pas le dossier des profils.

Le fonctionnement avec d'autres versions de Minecraft, d'autres systèmes ou des commandes propres à un serveur n'est pas garanti : testez toujours une action sans risque avant un événement.
